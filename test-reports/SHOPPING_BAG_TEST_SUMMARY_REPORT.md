## 3. Выводы

Фактически проверенные действия выполняются согласованно: корзина обновляется, характеристики товара сохраняются, две разные позиции различимы, удаление одной не затрагивает другую. Отображаемые денежные значения согласуются с компонентами расчёта для проверенных состояний.

**Особенность UI:** при платной доставке `$7.95` отображаемый `Sub Total` для одного товара равен `$56.66`, то есть включает доставку; при бесплатной доставке для Qty 2 он равен `$97.42`. Это **наблюдение, а не универсально подтверждённое правило**; `REQ-AE-018` остаётся гипотезой, а `Q-AE-05` требует уточнения.

**Ограничения:** исходные данные для `TC-AE-105` и `TC-AE-106` отличались от проектных предусловий; их буквальные варианты остаются непроверенными. Отсутствие дефектов в шести проверенных вариантах не подтверждает качество всего модуля. Негативные сценарии, крайние значения Qty, различные скидки и налоги не исследованы полностью.
