## 1. Цель и условия

Проверить открытие поиска, ввод и отправку запросов, релевантность результатов и обработку нестандартных значений. Использовать только обычные пользовательские действия на публичном сайте; не обходить anti-bot-защиту и не создавать массовый трафик.

**Перед выполнением:** записать дату и время с часовым поясом, URL, версию Chrome/другого браузера, ОС, регион, язык, VPN (если есть), гостевую/авторизованную сессию и видимые всплывающие окна. Для позитивного запроса выбрать товар, фактически доступный в каталоге на момент проверки. Для негативного — произвольную бессмысленную строку. Не фиксировать личные данные, cookies и токены в репозитории.

## 3. Тестовые данные: классы эквивалентности

| Класс | Пример | Что изучаем |
|---|---|---|
| Существующий товар | Название реально доступного товара (выбрать перед запуском) | Релевантность выдачи |
| Неизвестная строка | Произвольная бессмысленная последовательность | No results, рекомендации и их обозначение |
| Пустое значение | `""` | Поведение пустого ввода |
| Только пробелы | `"   "` | Нормализация |
| Регистр | Верхний/нижний регистр того же запроса | Чувствительность к регистру |
| Пробелы по краям | `" jeans "` | Обработка внешних пробелов |
| Буквы и цифры | Короткий буквенно-цифровой запрос | Обработка обычных символов |

**BVA:** границы минимальной/максимальной длины запроса пока не заданы документированным требованием. Не выдавать односимвольный ввод за полноценную проверку границ.
